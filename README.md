# LIRA — Literature Intelligence & Research Assistant

> An AI-powered research assistant that helps you discover academic papers, understand them in plain language, synthesize literature, and identify potential research gaps.

LIRA is a lightweight, browser-based research assistant built for students, researchers, and anyone exploring a new research topic.

Instead of manually searching through papers one by one, LIRA lets you search **arXiv**, quickly understand individual papers, select the most relevant ones, and generate a structured literature review with AI-powered synthesis and research-gap analysis.

---

## ✨ Features

### 🔎 Academic Paper Search

Search arXiv by topic and retrieve relevant research papers directly from the browser.

* Search by any research topic
* Filter by academic category
* Sort by newest papers or relevance
* Retrieve 10, 20, or 30 papers
* View paper metadata, authors, publication date, and abstract
* Open the original arXiv paper or PDF

Supported categories include:

* Artificial Intelligence (`cs.AI`)
* Machine Learning (`cs.LG`)
* Computation & Language (`cs.CL`)
* Computer Vision (`cs.CV`)
* Robotics (`cs.RO`)
* Statistics / Machine Learning (`stat.ML`)
* Quantitative Biology
* Physics
* Mathematics
* Economics
* Electrical Engineering & Systems

---

### 🧠 AI Paper Explanations

Don't understand a paper's abstract?

LIRA can explain it in plain language using an AI model.

For each paper, it breaks the abstract down into:

* **The problem** — What problem is the research addressing?
* **What they did** — What approach or system did they propose?
* **What they found** — What results or claims are presented?
* **Why it matters** — Why is the research significant?

The explanation is explicitly constrained to the paper's title and abstract to reduce unsupported claims.

---

### 📚 AI Literature Review

Select multiple papers and generate a structured literature review.

LIRA produces:

1. A high-level overview of the research area
2. A summary of each selected paper's contribution
3. A synthesis connecting themes and relationships between papers
4. Research gaps exposed by the selected literature
5. References to the original papers

The generated synthesis uses numbered citations such as `[1]`, `[2]`, etc., corresponding to the selected papers.

---

### 🚧 Research Gap Detection

One of LIRA's main goals is helping researchers move beyond simply summarizing papers.

The AI analyzes the selected literature to identify potential gaps such as:

* Unaddressed problems
* Areas that have not been sufficiently tested
* Conflicting findings or approaches
* Missing evaluations
* Questions that remain unresolved

Each identified gap is connected back to the papers that support it.

> **Important:** Research gaps generated by LIRA should be treated as starting points for investigation, not as definitive claims about the state of the field.

---

### 📄 Markdown Export

Generated literature reviews can be exported as a `.md` file containing:

* Literature-review overview
* Reviewed papers
* Paper contributions
* Cross-paper synthesis
* Research gaps
* References

This makes it easy to move the generated review into a research notebook, documentation system, or writing workflow.

LIRA intentionally keeps the architecture simple.

```text
┌─────────────────────┐
│      User           │
│  Research Topic     │
└──────────┬──────────┘
           │
           ▼
┌─────────────────────┐
│     LIRA UI         │
│     index.html      │
└──────────┬──────────┘
           │
           ├──────────────────────┐
           ▼                      ▼
┌─────────────────────┐  ┌─────────────────────┐
│      arXiv API      │  │      Groq API       │
│                     │  │                     │
│ Paper discovery     │  │ Paper explanation   │
│ Metadata            │  │ Literature review   │
│ Abstracts           │  │ Research gaps       │
└─────────────────────┘  └─────────────────────┘
           │                      │
           └──────────┬───────────┘
                      ▼
             ┌─────────────────┐
             │ Research Report │
             │                 │
             │ • Overview      │
             │ • Contributions │
             │ • Synthesis     │
             │ • Research gaps │
             │ • References    │
             └─────────────────┘
```

LIRA is currently implemented as a single-page application with vanilla HTML, CSS, and JavaScript.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Samad80/LIRA.git
cd LIRA
```

### 2. Run the application

Because LIRA is a client-side application, there is no backend to install.

You can open `index.html` directly in a browser, or serve it with a simple local HTTP server:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

### 3. Configure your AI model

Open **AI model settings** inside LIRA.

Add your Groq API key and select your preferred model.

The API key is stored locally for the application and is used directly when making requests to Groq.

---

## 🔐 API Key & Privacy

LIRA follows a client-side architecture.

Your Groq API key is entered by you and stored using browser storage. AI requests are sent directly from the browser to the Groq API.

The application does **not** require a custom backend to proxy AI requests.

However, because the application runs entirely client-side:

* Do not use this architecture for applications where API keys must remain secret.
* Do not share your API key with other users.
* Consider moving API requests behind a secure backend before deploying LIRA as a public multi-user service.

## 🔬 How LIRA Works

### Step 1 — Search

Enter a research topic such as:

```text
retrieval augmented generation
```

Choose an optional category and sorting method.

LIRA queries the arXiv API and displays the returned papers.

### Step 2 — Explore

Each result contains:

* Title
* Authors
* Abstract
* Publication date
* Category
* arXiv link
* PDF link

You can also ask LIRA to explain the paper in simpler language.

### Step 3 — Select Papers

Select the papers that are relevant to your research question.

### Step 4 — Generate Literature Review

LIRA sends the selected paper metadata and abstracts to the configured AI model.

The model generates:

```text
Overview
    ↓
Paper Contributions
    ↓
Cross-Paper Synthesis
    ↓
Research Gaps
    ↓
References
```

### Step 5 — Export

Download the generated literature review as Markdown and continue editing it in your preferred research workflow.

## ⚠️ Limitations

LIRA is designed as a research-assistance tool rather than an autonomous academic researcher.

Currently:

* Paper analysis is based primarily on **titles and abstracts**, not full PDF contents.
* Research-gap detection depends on the selected papers.
* AI-generated explanations and synthesis may contain errors.
* Generated research gaps require human verification.
* Search is currently focused on arXiv.
* There is no user account or cloud database.
* API usage is dependent on the user's Groq account and available limits.
* The client-side API-key architecture is intended primarily for personal/local use.

For serious academic work, always verify claims against the original papers.

## 🧪 Example Workflow

Suppose you are researching:

```text
Retrieval-Augmented Generation for Large Language Models
```

You could use LIRA to:

1. Search arXiv for RAG papers.
2. Filter the results to Machine Learning or NLP.

## 💡 Philosophy

LIRA is built around a simple idea:

> **Research should be about understanding the literature, not just finding papers.**

Finding papers is only the first step.

A useful research assistant should help you understand **what has been done, how different approaches relate to each other, what remains unresolved, and where new research might contribute.**
